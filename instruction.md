# LCR Compliance
Reconstruct Lead/Copper compliance; one table per case. Governed by 40 CFR 141.80(c)(3),141.86(a)-(e) in /app/data/reference/lcr_excerpts.pdf (count table included). PDF wins where silent; practice below wins where stated.
Cases under /app/data; settled_01/02 have <case>_signed.csv for checking. Files: systems.csv(system_id,period,population_served); inventory.csv(system_id,site_id,tier_lead,tier_copper,active,service_status,requires_pair); results.csv(system_id,site_id,sample_id,period,contaminant,liter,value,unit,qualifier,invalid_flag,collection_date) plus legacy.txt (same fields, disjoint by sample_id; union both); approvals.csv(system_id,sample_id,approval_type,effective_date,expiry_date; INVALIDATION names sample else ALL).
ug/L/1000; U or </0 lowest; J/B as-is. Apply every applicable rule; drops never count. Join on system+site else drop. invalid Y excluded only with matching INVALIDATION in dates. Tier per contaminant/system/period: keep highest tier with active (Y+ACTIVE) site. Lead requires_pair Y: fifth counts, first ignored; lone liter excludes site; else NA. Survivors=eligible_n.
Percentile: 0=0.0000+violation; <5 max; =5 mean top2; >5 ceil(n*0.9)th ascending; ties site_id,date. Half-up 4dp. Exceed if >0.010 lead, >1.3 copper. YES/NO.
Minimum from PDF only; standard unless reduction covers period (start in dates); triennial wins if conditions hold. Minimum sets violation only. Prior two=preceding present; gaps none; early missing compliant but approval needed.
STANDARD_SEMIANNUAL if exceed/violation/default; REDUCED_ANNUAL if clean+annual+>=1 prior exceed; REDUCED_TRIENNIAL if clean+triennial+clean current+prior2. Followup: NONE alone; MON_VIOLATION if minimum unmet; PE/SLR lead row only; WQP exceeding row only. Join MON_VIOLATION|PE|SLR|WQP.

Key system+period+contaminant, order free. Missing/dup/unknown/nonnumeric fail. Tol 0.0001; counts/strings exact.
